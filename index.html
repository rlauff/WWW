Robert Lauff

PhD candidate · Technische Universität Berlin

Advised by Stefan Felsner. My research interests include structured graph theory and combinatorics. Recently I have focused on finding constructions for nice cycles and paths on graphs and polytopes, such as rainbow cycles or facet-Hamiltonian cycles, and Gray-codes in general.

Software Projects

See the respective repositories for more detail and current status. If you are interested in contributing to any of them, feel free to reach out.

  1. Rust

    Daedalus

    A Quoridor engine trained by self-play, in the style of AlphaZero. The board, the search and the network all run in the browser — the engine is compiled to WebAssembly and the network to WebGPU. Includes automatically generated puzzles: positions with exactly one winning move that a plain search cannot find.

    Web App
  2. Python

    Dead-or-Alive

    Automatically generated Tsumego using KataGo’s ownership map. Decide if a group is dead or alive.

    Web App
  3. Rust

    Subtext

    An esoteric programming language based on RegEx matching.

    GitHub Web Sandbox
  4. Julia

    UniTriSat

    A Julia package to compute (regular) unimodular triangulations of lattice polytopes using SAT solvers.

    GitHub
  5. Rust

    Rhombic Strips

    Software to compute rhombic strips in a given lattice. The lattice can be passed via a file or built in a simple GUI.

    GitHub Web Sandbox
  6. Rust

    Quiver Mutations

    An efficient implementation of quiver mutations. The quiver can be built and manipulated using a simple GUI.

    GitHub Web Sandbox
  7. Rust

    Hanabi

    An implementation of the card game Hanabi. Strategies can be added via a trait — contributions welcome.

    GitHub
  8. Rust

    Quoridor

    My first Rust project: a simple AI for Quoridor, based on brute-force backtracking with a score heuristic. Includes TUI visualizations of the board.

    GitHub
